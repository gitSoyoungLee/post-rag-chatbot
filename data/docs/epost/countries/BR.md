# 브라질(BR) 국제우편 발송조건

한국에서 브라질(으)로 보낼 수 있는 서비스: 국제특급(EMS), EMS프리미엄, 국제소포(항공/선편), 국제통상(서신·인쇄물·소형포장물 등), K-Packet

## 브라질 국제특급(EMS)

### 기본 조건

- 요금적용지역: BR 지역
- 취급지역: 전지역
- 도착통지: 취급
- 최대규격: 길이<= 1.05m , 길이+둘레<= 2m
- 제한중량(g): 30,000
- 배달횟수: 3
- 배달소요일수(서류): 10
- 배달불능시 보관기간: 7
- 배달불가요일: 토,일,공
- 세관신고서 작성기준: 모두첨부

### 긴급공지

- 우편 물량 및 항공 운송편(환적 등)에 따라 발송 및 배달이 지연될 수 있음

### 접수 시 주의사항

- 유학서류, 선적서류(선하증권/Shipping document 등) EMS 접수 금지* 시한성/재발급 불가 우편물은 반드시 EMS 프리미엄으로 접수 문의 - 지연, 분실 시 간접피해 보상 불가 - 시행 : '21. 2. 23
- 상시지연이 발생하는 배달 지연 국가로 지연 시 손해배상이 되지 않으며 이에 시한성 우편물은 EMS 프리미엄으로 접수할 것을 권장합니다.
- 포장상태와 관계없이 김치 전체 접수중지
사유 : 성수기 항공 운송편부족과 접수 물량증가로 인한 발송지연 접수중지: 2020.11. ~ <출처: 우정사업본부 국제사업과, 2021. 10. 28>
- 사서함 (PO BOX) 취급
- 주소변경 및 반환청구 가능(협조사항)
- CN22, CN23의 여백에 수취인의 관세납부번호(CPF, 000.000.000-00) 기재 요청(2019.11.15. 우정사업본부 국제사업과)
- 우편번호 검색 기능은 해당국에서 제공하는 배달보장일 기준의 우편번호 단위로 검색 됨(앞 5자리)
- 공백 포함, 전체 우편번호 직접 입력 가능 (9자리, 99999 9999)
- 발송인,수취인 주소,세관신고서(내용품명 등) 영문 작성 필수(한글 혼용 금지)
- 통관조치에 필요한 정보(이름, 발/수취인 주소, 전화번호, 상품상세정보 등)가 없는 우편물 발송 금지 (UPU회람-100, ‘18.9.6.)
- 내용품
의 액체류가 포함될 경우 항공탑재 불가로 반송 처리 안될 수 있음

### 금지·제한품목

- 금지품목 : 주류, 알콜성 음료, 담배류, 액체류, 화장품, 집에서 녹화한 CD, 건어물(오징어, 명태, 쥐포), 중고품, 의약품(양약, 한약, 영양제 등), 라벨, 선박부속품,
- 음식물은 주로 반송됨(원산지/유통기한이 표시된 가공식품만 소량 가능, 한약은 자체 폐기)
- 발송물이 판매용이 아닐경우, Sample 혹은 Not for Sale 이라는 문구 등을 기재

### 배달특이사항

- 배달지연 승인국가
- 배달시도는 1회이며 배달불능시 즉시반송
- 주소불명, 수취인부재, 기표지탈락의 경우 주소에 대한 문의없이 즉시 반송조치

### 세관·통관사항

- CN22, CN23의 여백에 수취인의 관세납부번호(CPF, 000.000.000-00) 기재 요청(2019.11.15. 우정사업본부 국제사업과)
- 발송인,수취인 주소,세관신고서(내용품명 등) 영문 작성 필수(한글 혼용 금지)
- 통관조치에 필요한 정보(이름, 발/수취인 주소, 전화번호, 상품상세정보 등)가 없는 우편물 발송 금지 (UPU회람-100, ‘18.9.6.)
- 모든 비서류 발송품은 통관을 위해 수취인의 Tax ID 번호가 필요
- 우편발송수수료(Fee for Postal Dispatch, 통관회부료) 도입으로 통관에 제출되는 모든 우편물에 대하여 15BRL 지급 필수, 미지급 시 접수지로 반송
- 면세한도: 선물 50 USD 이하
