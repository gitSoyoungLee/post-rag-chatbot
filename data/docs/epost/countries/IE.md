# 아일랜드(IE) 국제우편 발송조건

한국에서 아일랜드(으)로 보낼 수 있는 서비스: 국제특급(EMS), EMS프리미엄, 국제소포(항공/선편), 국제통상(서신·인쇄물·소형포장물 등), K-Packet

## 아일랜드 국제특급(EMS)

### 기본 조건

- 요금적용지역: 3 지역
- 취급지역: 주요안내사항 참조
- 도착통지: 취급
- 최대규격: 길이<= 1.5m , 길이+둘레<= 3m
- 제한중량(g): 30,000
- 배달횟수: 1
- 배달소요일수(서류): 10
- 배달불능시 보관기간: 21
- 배달불가요일: 토,일,공
- 세관신고서 작성기준: 모두첨부

### 긴급공지

- 우편 물량 및 항공 운송편(환적 등)에 따라 발송 및 배달이 지연될 수 있음

### 접수 시 주의사항

- 유학서류, 선적서류(선하증권/Shipping document 등) EMS 접수 금지*시한성/재발급 불가 우편물은 반드시 EMS 프리미엄으로 접수 문의 - 지연, 분실 시 간접피해 보상 불가 - 시행 : '21. 2. 23
- 포장상태와 관계없이 김치 전체 접수중지
사유 : 성수기 항공 운송편 부족과 접수 물량증가로 인한 발송지연 접수중지: 2020.11. ~
<출처: 우정사업본부 국제사업과, 2021. 10. 28.>
- 사서함 (PO BOX) 취급
- 주소변경 및 반환청구 불가능
- 세관 신고서 정보로 (특히 HS CODE) 인한 반송 사례가 많으므로 내용품명 및 HS CODE 정확하게 작성하시도록 안내(특히, 액체류, 식품류 등의 접수시 유의)
- 아일랜드(IE)행 EMS 서류 우편물 접수 시 HS CODE (서류 - 4911100000) 및 내용품명 (Application form, Poster 등) 상세히 입력
* 사전접수 우편물의 경우 연계접수버튼을 통하여 데이터를 불러온 후 내용품정보에서 HS CODE (서류 - 4911100000) 및 내용품명 (Application form, Poster 등) 입력
- 수취인 주소 우편번호(post code) BT1~BT82는 영국(GB) 북아일랜드이므로 영국으로 접수해야함

### 금지·제한품목

- 금지품목 : 동물 부산물(가죽, 깃털), 알코올, 의약품, 주류, 담배, 소화기, 소화기 부속물
- 제한품목 : 컴퓨터 및 부속품은 상업송장(invoice)에 정확한 품명 기재

### 배달특이사항

- 수취인 주소 우편번호(post code) BT1~BT82는 영국(GB) 북아일랜드이므로 영국으로 접수해야함

### 세관·통관사항

  ※ 계약고객우편물(B2C)의 물품에 대하여 부가가치세 부과 (시행일자 : EU국가 ’21.7.1.)
- 면세한도: 선물 22 EUR
- 세관 신고서 정보로 (특히 HS CODE) 인한 반송 사례가 많으므로 내용품명 및 HS CODE 정확하게 작성하시도록 안내(특히, 액체류, 식품류 등의 접수시 유의)
- 아일랜드(IE)행 EMS 서류 우편물 접수 시 HS CODE (서류 - 4911100000) 및 내용품명 (Application form, Poster 등) 상세히 입력
* 사전접수 우편물의 경우 연계접수버튼을 통하여 데이터를 불러온 후 내용품정보에서 HS CODE (서류 - 4911100000) 및 내용품명 (Application form, Poster 등) 입력

## 아일랜드 EMS프리미엄

- 최대규격: 최대길이<=2.74m , 최대길이+둘레<=3.3m  ※ 가장 긴 변의 최대길이는 274cm이하

- 교부보관기간(일): 7
- 배달불가요일: 토,일,공

## 아일랜드 국제소포(항공/선편)

### 기본 조건

- 요금적용지역: 항공 3 지역 선편 3 지역
- 교부보관 기간(일): 항공 16 선편 16
- 보험취급가액(SDR): 83(1SDR=1,749원)
- 최대규격: 최대길이<= 1.5m , 최대길이+둘레<=3.0m
- 제한중량(g): 20000
- 보통소포 배달통지취급: 취급안함
- 보험소포 취급여부: 항공 취급 선편 취급
- 주소변경/반환청구: 항공 취급안함 선편 취급안함

### 접수 시 주의사항

- 아일랜드(IE) 행 식품은 아일랜드 세관에서 반송되는 경우가 있으므로 접수 시 유의 및 고객 안내 철저
- 평균송달소요일수(선편): 80~100일

### 금지·제한품목

- 금지품목 : 동물 부산물(가죽, 깃털), 알코올, 의약품, 주류, 담배, 소화기, 소화기 부속물
- 제한품목 : 컴퓨터 및 부속품은 상업송장(invoice)에 정확한 품명 기재

### 세관·통관사항

- 면세한도 : 선물 45 EUR 이하 (2021.09.27. 수정 본부 국제사업과)
