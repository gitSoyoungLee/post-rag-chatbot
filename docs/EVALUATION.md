# 품목 판정 평가

정답 세트로 **품목 판정 정확도**와 **근거 검색 재현율**을 측정하고, 오답 원인을 고친 과정을
기록한다.

## 측정 방법

```bash
uv run python scripts/evaluate_judgments.py            # 전체
uv run python scripts/evaluate_judgments.py --ids us-ems-laptop jp-ems-jerky
```

- **대상 구간**: 검색 → 판정 → 인용 검증. 대화 분석(슬롯 추출)은 거치지 않고 국가·서비스·
  품목을 정답 세트에서 바로 넣는다. 슬롯 추출 오류와 판정 오류를 섞지 않기 위해서다.
- **판정 정확도**: 예측 상태가 정답 또는 허용 상태에 들면 정답. 규정이 모호한 사례(예: 미국
  김치는 음식물 금지와 캔 용기 조건부 접수가 함께 있음)에만 허용 상태를 두었다.
- **검색 재현율(Recall@5)**: 정답 근거 문서의 정답 구절이 담긴 청크가 근거 5개 안에 있는 비율.
  정답 구절이 없는 '제한 없음' 사례 8건은 제외한다.
- 결과는 `evals/results/judgments_<날짜>_<커밋>.json`에 실행 조건과 사례별 근거·인용·이유와
  함께 저장한다.

### 1. 공통 금지물품 문서가 근거에서 잘림

국가 문서 결과 뒤에 공통 문서를 붙인 뒤 앞에서 5개를 잘라, 국가 문서가 5개 이상이면 공통
문서가 항상 빠졌다. 노트북·블루투스 이어폰이 '제한 없음'으로 나왔다. 금지 물품을 보내도
된다고 안내하는 가장 위험한 오류다. 공통 문서 자리를 2개 보장하도록 고쳤다.

고친 직후 정확도가 **오히려 떨어졌다**(72.7% → 54.5%). 공통 문서는 Markdown 표라서, 모델이
표 기호(`|`, `**`)를 빼고 인용하면 글자 비교에서 탈락했기 때문이다(인용 검증 실패 9 → 18건).
검색 수정 자체는 맞았고, 인용 검증의 약점이 드러난 것이다.

### 2. 인용 검증이 정상 인용을 탈락시킴

실패한 인용을 원문과 한 글자씩 대조해 보니 내용이 아니라 표기 차이였다. 표 기호, 말줄임표,
이스케이프 기호(`\*`), 목록 기호(` - `), 콜론 앞뒤 띄어쓰기 등이다. 비교할 때 이런 표기만
걷어내고 글자 순서는 그대로 대조하게 했다. 생략 표시로 나뉜 인용은 조각마다 원문에 있어야
하고, 생략 표시 없이 중간을 건너뛴 인용은 계속 탈락시킨다. 검증을 느슨하게 만들어 지어낸
인용이 통과하지 않도록 테스트로 고정했다.

### 3. 검색 재현율 (38/47 → 46/47)

| 시도 | Recall@5 |
|---|---:|
| 검색어를 코드로 구성 (`US ems 담배 기타 금지 제한 통관`) | 38/47 |
| k를 5 → 8로 늘림 | 41/47 |
| 검색어를 청크 경로와 같은 한글로 (`미국 국제특급(EMS) 금지·제한품목 담배`) | 43/47 |
| + 표 행 단위 청킹, 공통 문서는 품목 중심 검색어, 품목명 키워드 우선 | **46/47** |

- k를 늘리는 것보다 검색어 표현을 문서와 맞추는 게 효과가 컸다.
- 「보낼 수 있는/없는 물품」 표를 1,200자로 자르면 한 청크에 품목 10여 개가 섞여, 향수 행이
  든 청크가 12위, 라이터 행이 든 청크가 19위까지 밀렸다. 표는 행마다 청크로 나누고 머리글을
  붙였다.
- 표를 행으로 나누자 기존 중복 제거(같은 섹션은 청크 하나만)가 표 전체에서 행 하나만 남겼다.
  중복 제거 기준을 청크로 바꿨다.
- 남은 1건(AA 건전지)은 원문 표기가 "건전지 (AA/AAA)"라 품목명이 그대로 일치하지 않는다.

## 정답 검토와 재채점

작성자가 원문과 대조해 정답 3건을 고쳤다.

| 사례 | 초안 정답 | 검토 후 | 근거 |
|---|---|---|---|
| 미국 EMS 과자 | 금지 | 조건부 (충돌도 인정) | 미국 금지품목에 '음식물'이 있지만, 우체국 「미국행 식품 사전신고」 안내는 FDA 사전신고 후 식품 발송을 안내하고 개인 간 비상업적 식품은 적용을 완화한다고 한다 |
| 미국 국제소포 과자 | 금지 | 조건부 (충돌도 인정) | 같은 근거 |
| 태국 EMS 과자 | 금지 | 조건부 (충돌도 인정) | 같은 태국 문서에 제한품목 '음식물'과 '개인 음식물은 적절한 양이면 FDA 허가서 불필요'가 함께 있다 |

검토 과정에서 정한 원칙: 목록에 '음식물'처럼 묶어 적힌 경우는 다른 안내에 조건이 있으면 조건부로
본다. 물품 이름이 직접 적힌 경우(참기름, 녹차, 껌 등)는 금지로 둔다.

공통 안내의 「항공탑재금지 물품 상세 예시」 표에 있는 '식품류: 시중 판매 완제품 가능'은 한국에서
항공기에 실을 수 있는지에 대한 기준이라, 도착국 통관 근거로는 쓰지 않았다.

같은 실행 결과를 검토 후 정답으로 다시 채점했다(모델을 다시 실행하지 않음). 검색 재현율은 정답
구절이 바뀐 3건 때문에 다시 실행해야 비교할 수 있어 표에서 뺐다.

| 커밋 | 초안 정답 기준 | 검토 후 정답 기준 | 금지 물품을 '제한 없음'으로 안내 |
|---|---:|---:|---:|
| `97727ce` | 40/55 | 39/55 (70.9%) | 2 |

'금지 물품을 제한 없음으로 안내'는 사용자가 믿고 보내면 반송·폐기되는 가장 위험한 오답이라 따로
센다.

## 남은 오답 (`d07014c` 기준)

| 사례 | 정답 | 예측 | 원인 |
|---|---|---|---|
| 미국 EMS 노트북 | 금지 | 근거 부족 | 모델 인용문에 제어 문자(`\x00`)가 섞여 인용 검증 실패. `e5a9e99`에서 수정 |
| 영국 EMS 엽서 | 제한 없음 | 근거 부족 | 표의 떨어진 칸을 생략 표시 없이 이어 붙인 인용. 규칙대로 탈락 |

초안 정답 기준으로는 미국·태국 과자가 오답이었으나, 검토 후 정답(조건부) 기준으로는 정답이다.
대신 미국 국제소포 과자(금지로 판정)가 검토 후 기준에서 오답이 된다.

`7667dfa`의 판정 프롬프트에는 '목적지 국가의 금지 규정이 일반 안내보다 우선'이라는 원칙을 넣었는데,
검토 후 정답의 원칙(묶어 적힌 '음식물'은 조건부)과 맞지 않아 고쳐야 한다. 아직 측정하지 못했다.

## 한계

- **개발 세트로 튜닝했다.** 위 수치는 오답을 보며 고친 같은 정답 세트에서 잰 것이라 낙관적이다.
  일반화 성능을 말하려면 개선 과정에서 보지 않은 별도 세트로 다시 재야 한다.
- **실행마다 결과가 달라진다.** 같은 7건을 다시 돌렸을 때 4건의 판정이 바뀌었다. 지금 코드는
  `temperature`를 보내지 않는다(이전 모델 `gpt-6.1-sol`이 이 값을 거부해서). 수치는 한 번 실행한
  값이며, 여러 번 실행한 평균과 편차를 함께 보고해야 한다.
- 정답 세트는 AI 도구로 초안을 만들고 작성자 한 명이 검토했다.
